# Public source mirror / 公开源码镜像

This mirror omits private operational records, task receipts, dataset splits,
review media and personal calibration. Real machine addresses and storage
locations have been replaced by documentation examples. Public algorithm code
and third-party license notices are retained.

这里是脱敏源码镜像。原生产 V1、生产文件和冻结证据保留在私有工作区；
公开镜像中的示例路径和占位值不具有生产权威，也不是完整恢复包。
执行和部署须另行准备私有配置、数据、权重和当前有效治理许可。

History was rewritten for privacy. Create a fresh clone for future public work;
do not merge an old private checkout or its history into these public branches.
Only reviewed, sanitized source may be published. Private evidence and recovery
bundles must remain outside public Git history.
