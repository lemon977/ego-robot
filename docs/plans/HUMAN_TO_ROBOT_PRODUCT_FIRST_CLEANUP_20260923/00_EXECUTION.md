# Human→Robot Baseline v1：007 产品优先与安全实删

本任务为新的 12 小时有限执行实例，承接已终态的 Convergence。四个 lane 为 scene、sensor、motion_product、compare；publisher 独占共享状态和清理。主会话 007/031，回归 0902_103/042，Sensor 0916_097/098/101。所有新写入位于项目内。离线视觉用途；training、control、physical deployment、external metric authority 均为 false。

## 必交执行

1. 007 固定帧 181–196：修正“角色全空”硬编码理由，分别验证已有角色、投诉像素覆盖、持续线缆实例、remove/protect/write 和 reference 张量消费。实例与输入合法后运行一次固定 ProPainter 小窗；独立复核新旧 Clean。只有可复核改善且留有验收时间才扩全片。031 牌边独立处理。
2. 031 不运行新 IK。限时 90 分钟独立从 q、固定 URDF 与完整安装复算第 47 帧及相邻帧，之后复算 007/031 Local 与 HuRo 的全量残差和极值。16 个左手 RGB 样本逐帧审阅。Sensor 复用 466 帧做独立技术复核。
3. 031 同物体 patch 采样必须使用实际有效中心深度，同实例连续邻域仅作一致性检查。Robot 表面对应必须绑定 URDF link 语义、实际 FK 和 optical-Z。连接件真实网格通过本地碰撞后端做分离、相交、孔洞及短窗查询。三项均需反例、真实调用、数组和可视证据。
4. 正确交付 15 槽位：007/031 主产品及全链、四 Clean、三 Sensor、两比较和四纯 Robot。新旧对照与质量状态分开，不用旧单面产品冒充全链。

## 清理保护和实删

第一批删除前冻结运行及条件任务依赖、最小复现与新旧对照、精确删除集。raw、processed、sealed 与项目外源绝对保护。当前正式消费者、必要环境、权重、资产和交付实体进入保留集。单个 I/O worker 检查大文件与无依赖副本；安全对象第一批实际删除。环境、工作树及历史大载荷放第二批，H9 前冻结迁移和恢复方案，H9 后只执行已核验批次。

删除逐对象追加 SELECTED→ISOLATED→CONSUMER_CHECKED→PURGED，失败回滚且不得覆盖新对象。同路径内容变化取消旧删除资格。旧收据保持原字节，通过新增清理收据记录历史载荷裁剪。隔离不是回收。清理后检验正式入口、resume、环境、最小失败包、视频导航和治理；报告逻辑删除量、项目净占用、新增产物量和可测分配空间。

## 停止和调度

H0–H3 完成登记、保护集、007 事实修复、独立 FK 与第一批安全删除。H3–H7 共享消费者真实调用及条件 Clean。H7–H9 产品、Sensor、比较及第二批删除冻结。H9–H10 只执行已核验删除并验证入口。H10–H12 收尾、解码、SHA、质量和清理终态。无等待时钟；条件提前满足即推进。CPU 总软上限 8 线程、主要重任务最多 2、清理 I/O worker 最多 1、GPU 单租约。仍有可执行实现待办时不得因一个数学候选失败提前宣布全部完成。
