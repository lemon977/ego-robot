# 007 后段全会话桌面供体探针（有限 CPU 任务）

目的：旧 19 供体在 192–196 帧的写入区没有可用桌面像素。用同一原始会话的其余帧检验这是否仅由稀疏供体集合造成；不生成 Clean，不改变旧质量结论。

- 固定目标：`get_potato_chips_0915_007` 的帧 192、196；固定供体：0–377 中除 181–196 以外的全部帧，按升序只评估一次。
- 复用已冻结的 `table_mask`、SIFT 留出匹配和几何门；使用物理左目 1280×960 原始图、现有人手与设备排除。目标写入区取旧 16 帧 attachment canary；任务物体 mask 用原始 uint16 标签读取，避免把盘子／薯片当桌面。
- 每个目标输出合格供体数、写入区零／一／三供体像素、掩码和源输入 SHA。三供体是既有诊断门；单供体只作来源线索，不取得 Clean 资格。
- 不改变阈值、不挑最好片、不做颜色拟合、不填像素、不重跑 ProPainter。两帧结果无论正负都终态化；若仍无覆盖，停止现有同会话平面供体路线，不断言所有视频背景都不存在。
- CPU 总软上限 8、GPU 0、墙钟上限 1 小时、同签名质量重试 0。任何产物只在本任务 attempt 内；旧 raw、历史结果与收据只读。四产品质量／采用均不因本探针晋升。
