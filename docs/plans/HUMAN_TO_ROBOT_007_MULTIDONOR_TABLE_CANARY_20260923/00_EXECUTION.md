# 007 多供体桌面固定窗诊断

有限任务：`human_to_robot_007_multidonor_table_canary_20260923`。只处理 `get_potato_chips_0915_007` 原帧 181–196，不覆盖任何旧结果，不扩全片。

冻结输入：上一任务实际 ProPainter 16 帧 Clean、写入／保护掩码、当前同会话原图；供体集合固定为上一桌面几何探针中通过既有门的 19 帧 `[144,152,160,176,184,216,248,264,272,280,288,296,312,320,336,344,352,360,368]`。每个目标帧排除同帧供体，重新执行同一留出几何门，失败供体不进入该帧合成。不按新画面挑供体、阈值或投诉位置。

每个合法供体只提供原人手／设备排除后颜色符合桌面代理的像素；当前目标的可见桌面训练区与留出区按固定空间棋盘分开。供体每通道颜色偏置仅由训练区中位数计算并截断到±25码值；报告留出区误差。被三份以上合法供体共同覆盖、且在新写入区内、不在保护区／任务物体区的像素，使用颜色校正后的逐通道中位数替换上一 Clean。其它像素保留上一 Clean；写入区外保持原图字节不变。不从邻域统计伪造某个像素的实际场景真值。

交付16帧数值、覆盖／拒绝分母、同帧Raw／上一Clean／桌面支持／新候选对照视频。独立抽查181／184／190／196；即使桌面局部改善，也不自动获得盘子、薯片、隐藏表面或完整Clean质量。若供体不足、颜色误差大、残手或边界仍明显，记质量拒绝，不原样重试或扩378帧。

预算：CPU最多1小时、≤8线程，不用GPU；一次正常运行，无同签名质量重试。原始、processed、archive、sealed和旧attempt均只读；所有新增文件在本任务attempt内。产品质量、训练、控制、真机和外部公制资格不因本任务升级。
