# 007 同会话桌面供体固定扩展探针

目标：在旧四供体全部未通过既有几何门后，以固定、不同的同会话帧表寻找一个**桌面像素**供体；不是重跑旧四帧、降低门或生成整幅 Clean。冻结 target 为帧184、旧 181–196 写入区、物理左目 resize-only 域；候选供体为 `range(8, 369, 8)` 中除 0／100／250／377 外的全部帧，运行前不按结果增删。沿用 `fit_heldout_homography` 的 SIFT、训练／留出划分和原 `25 fit inliers / 8 holdout inliers / 2px median / 4px P95` 门。对每个通过的供体，计算其合格桌面 mask warp 到 target 写入区的覆盖；仅以该覆盖最大、帧号最小的预定规则选一个诊断图。plate／chips／手／设备／未知像素均不得当作已测背景。无通过者保留全部拒绝码，不原样扩采、放宽门或伪造候选。

任务墙钟最多两小时、CPU总软预算8线程且此探针限制OpenCV 2线程；无GPU、无新模型、无训练或真机。仅一次固定运行，质量失败不重试。旧收据、raw、processed、archive、sealed及旧attempt字节只读。新增文件、缓存和临时文件仅在项目内。结果必须包括全部冻结供体分母、逐帧几何指标、可加载诊断图（若存在）及仍未解决的盘子／设备背景缺口；不升级四产品的质量或采用。
