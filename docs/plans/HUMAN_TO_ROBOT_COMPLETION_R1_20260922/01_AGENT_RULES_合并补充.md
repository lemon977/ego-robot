# 执行AI规则补充：合并到实际生效的项目规则，不覆盖原文件

适用：Human→Robot Baseline v1四支线。作者提供的是任务合同，不是运行状态。

## 默认读取与所有权
1. 只读当前操作入口指向的本轮版本、本规则、本线短卡、本线最新机器摘要。
2. 不在每次恢复时读所有V3/V4/V5历史、全仓库或所有日志。按失败码再定位。
3. 启动时确认实际工作目录、加载的项目规则和覆写来源。发现旧规则冲突，交由当前协调者登记解决，不偷偷选有利规则。
4. 只修改本线授权文件；共享Scene/renderer由线1、Robot/装配/入口由线3维护。其他线给最小复现，不复制新框架。
5. 不修改raw、sealed、旧收据、原URDF/mesh/骨长/关节轴/限位、其他线产物、用户既有训练与安全约束。

## 固定事实，不再猜
6. wrapper已mask_dilation=0并有回贴。设备缺失检查真实角色及输入路径，不预设二次膨胀。
7. 安装平移是Controller坐标每轴绝对±0.16m；0.05m相对原始先验。不得叠加M1。
8. 6mm/4°/6°是相对输入修正，不是人体帧间速度。
9. 007有效性全片为真不代表渲染没问题，也不能用valid切换解释全部闪烁。
10. 设备角色非空不证明设备全覆盖；模型权重/代码存在不证明已执行。

## 修改闭环
11. 每次修复必须对应：现象、最小失败复现、测试、差异、同测试复跑、固定范围回归、产物签名。
12. 每个明确故障包最多两轮证据驱动修复；不扫参数、不重复同签名质量运行、不重置预算。
13. 不通过删除断言/放宽阈值/改变分母/隐藏失败帧/忽略碰撞对让测试变绿。
14. 评价门与期望交付清单运行前冻结。worker无权自行修改；必要变更由既有合同负责人审查并使旧结论失效。
15. 新测试必须有能触发失败的反例。仅断言文件存在或exit=0不足以证明算法成功。
16. 实现了但消费者没有真实调用，记IMPLEMENTED_NOT_INTEGRATED，不记完成。

## 数据和算法边界
17. Raw几何和Clean外观分离。Clean及其生成像素不进入Depth/Object/Contact/标定/IK。
18. 允许合法结构的CANDIDATE_ONLY集成；语义质量失败限制采用，不阻止保存可诊断候选。
19. 不用无效节点补全骨架；不镜像左手、不无限保持、不把inferred提升为observed。
20. 不给NaN乘0后当成功屏蔽，计算前安全选择有效残差。
21. 物体保护是可信可见像素，不是时间安全带。上下文排除须进入实际reference输入。
22. 场景遮挡排除原人手/设备深度；深度必须同相机同量纲，未知明确输出UNKNOWN。
23. R1消费不可变R0，固定arm_q/腕/相机/物体/mount/placement，只在许可手指边界内优化。硬门退化整段回退。
24. HuRo比较为同输入本地R0对核心结果；不能让一方独享R1还宣称公平。

26. 真实模型调用、实际渲染输入和最终文件均绑定SHA。REUSED不等于本轮改善。
27. 程序完成、文件完整、质量通过、改善获证实四轴分开；NOT_RUN/UNKNOWN不得默认PASS。
28. 工作者提交不可变结果；单一publisher重算指标并发布。独立复核不先看作者“成功”结论。
29. GPU单租约、CPU总软上限8含编码和子进程；不下载新模型、不训练、不人工标定、不扩156条。
30. 两次连续更新没有新测试/产物必须收缩问题或交接；不能重复宣告“继续排查”。
31. 保持OFFLINE_VISUAL、training_eligible=false、control_ground_truth=false。完成本轮终态不等于目标成功。
