# 031 全时间轴手表面—Stereo 深度差与纸牌遮挡审计

接续封存的16帧表面诊断，在原149帧时间轴和原102帧右手有效输入上运行一次CPU几何重算。输入固定为同一物理左眼的HaWoR MANO三角面、Stereo光学Z、SAM手区及既存三张纸牌可见实例mask。先按模型与Stereo的同像素、深度有效/LR一致、手区内部及局部连续性筛选，再以独立纸牌可见mask膨胀排除其边界。任一纸牌实例在该帧语义UNKNOWN，则该帧的严格“已排除全部纸牌”指标为UNKNOWN，不将空mask当作没有纸牌。

输出149行账本、同域全片诊断视频和全时间轴曲线。分别报告纸牌前表面保护前后在同一帧的样本数与深度差；不从深度差拟合腕偏置，不修改HaWoR/R0/IK或产品，不称真实手表面、外部公制精度或Contact。CPU上限一小时，无GPU、无模型推理、无同签名质量重试。旧产物只读，所有新写入在本项目内。
