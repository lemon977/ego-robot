# 007 供体空间内插资格（有限 CPU 任务）

上轮两帧全会话探针发现旧稀疏集合漏掉 12 对几何合格供体，但匹配误差只在匹配点处验证，不能证明远处被遮挡桌面仍可可靠投影。本任务仅对冻结的 192／196 帧及其已合格的供体对作空间支持审计。

- 冻结对：192←115／135／170／175／281／282／336／363；196←48／51／197／377。原几何门、图像域和人手／设备／物体排除不变；不得重新选择供体、放宽阈值或生成 Clean。
- 重建原 SIFT 匹配及 RANSAC，检查本次矩阵与原函数输出一致。用 **fit 内点**在供体和目标图像分别形成凸包；只有来自供体凸包内、且落在目标凸包内的同域有效桌面像素才记“内插支持”。仅一侧凸包通过的像素属于外推，不授予来源资格。holdout 点只验证几何，不参与凸包生成。
- 每对保存内点空间分布、两侧凸包和内插支持；汇总目标写入区零／一／三供体及与旧未限制支持的差异。凸包内插仍不是隐藏桌面真值，也不证明颜色／物体正确。
- CPU、1小时、无 GPU、一次 attempt、无同签名质量重试；旧产物只读，新增仅项目内。若两帧内插支持不足，停止这一路线的 Clean 扩片；若仍有支持，后续必须先做固定窗颜色与边界审阅。
