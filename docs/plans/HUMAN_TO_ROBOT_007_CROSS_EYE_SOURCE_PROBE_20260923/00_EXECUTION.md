# 007 同时刻跨眼桌面来源探针

任务：`human_to_robot_007_cross_eye_source_probe_20260923`。一次 CPU 有限诊断，最多 1 小时、0 GPU；不生成 Clean、Depth、公制点云或产品。

固定 `get_potato_chips_0915_007` 的 181、184、192、196 帧。目标是已封存 physical-left `sourceIndex=1` 的 1280×960 Raw 与合法写入区；候选来源是同一 SBS 视频、同一帧 physical-right `sourceIndex=0`，仅 crop＋resize，不做旧 lens remap。核对从同一解码帧抽出的 physical-left 与已保存 Raw 的像素域差异；错帧、眼别或图像域不闭合即拒绝。

只在两眼可见的桌面区域用既有 SIFT／RANSAC 留出匹配估计平面映射。供体桌面用保守颜色与人手／设备排除代理；匹配内点凸包同时限制左右两侧，只统计写入区中真正位于支持域的像素。右眼没有独立人手实例真值，任何颜色代理的漏检都要标注为风险，不能把支持数升级为真实隐藏桌面。

结果保存每帧：图像域检查、匹配数量与留出误差、内点空间支持、写入区分母、可用跨眼像素及拒绝原因；保存诊断掩码和 SHA。即使局部支持非零，也只说明下一步值得审阅，不能直接补图、扩全片、放行 Stereo metric、改变产品质量状态或使用在线因果输入。旧结果只读；所有输出、缓存和临时文件限项目内。
