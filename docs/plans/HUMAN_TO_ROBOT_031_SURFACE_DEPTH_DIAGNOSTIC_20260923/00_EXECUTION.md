# 031 可见手表面—Stereo 深度诊断（有限 CPU 任务）

本任务只在 `play_cards_0915_031` 的原有效右手区间 47–148 内，预先固定 16 个等间隔帧，读取既存 HaWoR MANO 顶点、MANO 拓扑、原 RGB、16 位 SAM 手区与既存 Stereo 光学 Z。用同一物理左眼相机内参将 MANO 三角面光栅化，比较同像素的模型前表面与 Stereo 可见表面；仅保留手区内部、左右一致、有效且局部连续的深度。

输出 16 帧实图对照、逐帧样本数及带符号深度差。物体遮挡、手区上游依赖 HaWoR ROI、Stereo 开发级资格以及未知三维对应均必须保持限制；不拟合深度偏置，不据此修改 wrist、IK 或产品，不称解剖中心真值或外部毫米精度。

预算：CPU 1 小时，无 GPU，无模型推理，无质量失败原样重试。旧数据及收据只读；所有新产物位于本项目内。终点是可复算的几何诊断与完整解码，而非产品质量通过。
